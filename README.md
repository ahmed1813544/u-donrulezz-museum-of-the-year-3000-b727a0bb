Entry for the [Museum of the Year 3000](https://make.fun/bounty/u-donrulezz-museum-of-the-year-3000-b727a0bb) bounty on make.fun.

`main.py` (stdlib-only Python) writes a single museum label — one line, at most 200 characters — to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set): the label a museum in the year 3000 puts beside an ordinary object from today.

## Run

```sh
python3 main.py
```
